# Code of Conduct

## Our Commitment

Mints Global ERP is an internal project built and maintained by Mints Global employees, interns, and contractors. We're committed to keeping collaboration on this project professional, respectful, and productive for everyone involved — regardless of role, department, or seniority.

## Expected Behavior

- Be respectful and constructive in code reviews, issues, and discussions.
- Assume good intent; ask clarifying questions before assuming a mistake was careless.
- Give feedback on the code and the work, not the person.
- Credit collaborators and be transparent about AI-assisted contributions where relevant.
- Keep discussions in the appropriate channel (GitHub for code/technical decisions, Discord `#dev-requests` / `#support` for quick questions).
- Protect sensitive data — never commit credentials, client data, or internal business information into the repository.

## Unacceptable Behavior

- Harassment, discrimination, or personal attacks of any kind.
- Dismissive or demeaning comments toward interns or junior contributors.
- Publicly sharing repository contents, screenshots, or credentials outside authorized channels.
- Circumventing the PR review process for non-trivial changes.

## Scope

This applies to all project spaces: the GitHub repository (issues, PRs, discussions, commits), the internal Discord server's dev channels, and any related project communication.

## Reporting

If you experience or witness a violation of this Code of Conduct, report it to your manager, the Project Lead, or an Admin directly. Reports will be handled discreetly and taken seriously.

## Enforcement

Founders and Admins are responsible for enforcement and may take any action they deem appropriate, including a warning, restricted repository access, or escalation through standard HR channels.
